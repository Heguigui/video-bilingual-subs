# 用法

[English](../USAGE.md) · `中文`

## 调用

```
/video-bilingual-subs <url 或路径> [输出路径]
```

不给输出路径时，成片落在工作目录下的 `<名称>.zh-en.mp4`，旁边同时生成 `zh-en.srt` 和 `en.srt`。

## 输入

| 输入 | 行为 |
|---|---|
| 网页 URL | 用 PowerShell（`Invoke-WebRequest`，走系统代理）抓页面，再从标记里找播放器 |
| 直链 `.m3u8` | 直接使用；从 master 里挑一路清晰度 |
| 直链 `.mp4` | 直接下载，不分段 |
| 本地文件 | 跳过下载 |

需要登录的页面，只要抓取时带上浏览器同款 cookie 就能用。签短期 URL 的付费播放器，必须在链接还有效时抓。

## 选清晰度

从高往低：1080p → 720p。除非明确要求，不要上 4K——烧录要整片重编码，耗时会翻倍，字幕并不会因此更清楚。

## 交付方式

- **默认——烧录成片。** 中文在上、英文在下，英文软轨内嵌，`+faststart`。
- **只要字幕。** 走完 1–6 步，交付 `zh_en.srt`。不重编码、不掉画质，样式交给播放器。

## agent 必须守的质量规则

- 术语在翻第一行之前就定死，之后不许漂。产品名保持原样；领域词按事先定好的词表走。
- 口语保持口语。语气词、缩写可以去掉，信息不能丢。
- 代码、命令、界面文案原样照抄，不翻译。
- 一个块可以拆成多条中文 cue，也可以合并，但绝不允许挂到相邻块的 id 上。

## 什么才算「完成」

1. `ffprobe` 时长与源片相差在几秒以内。
2. 片头、四分之一、中间、四分之三、片尾抽帧，字幕都在画面上，中文在上英文在下，没有被裁掉。
3. 抽检一条 SRT cue，和该时间点实际所说的话对得上。
4. `check_srt.py` 报告 0 叠时、0 超长行。

没跑完 1–4 就报完成，等于猜。
